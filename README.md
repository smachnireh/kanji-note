Минималистичный справочник и тренажёр для изучения базовых японских иероглифов (93 кандзи) с поддержкой умного поиска по русской и японской раскладке, флеш-карточками, поурочным делением и интерактивными тестами.

Работает полностью в браузере без серверов и бэкенда (offline-first). Прогресс сохраняется в `LocalStorage`.

---

## Возможности

- **93 кандзи из канонической программы**:
  - Четкое начертание знака и число черт.
  - Чтения Он (катакана) и Кун (хирагана).
  - Русская транскрипция (система Поливанова) и латиница (Hepburn).
  - Наглядные этимологические ассоциации и мнемоники.
  - Примеры слов и словосочетаний с озвучкой (Web Speech API).
- **Умный поиск**:
  - Поиск по чтению на русской клавиатуре (например, ввод «хи» находит иероглиф `火` и слова с чтением «хи»).
  - Поиск по значению («огонь», «вода», «человек»), ромадзи (`hi`, `mizu`) или самому иероглифу.
- **Поурочное обучение**:
  - 10 структурированных уроков (по 10 иероглифов в уроке).
  - Детальный разбор каждого знака и отслеживание прогресса по урокам.
- **Флеш-карточки**:
  - Двусторонние карточки с 3D-переворотом и интервальным повторением («Повторить» / «Знаю!»).
- **Тесты и прописи**:
  - Тестирование методом выбора правильного ответа (4 варианта).
  - Ручной ввод чтения/перевода с интеллектуальной проверкой.
  - Интерактивный холст с сеткой «田» для практики написания от руки.
- **Минималистичный интерфейс**:
  - Глубокие изумрудно-зеленые и золотые тона в стиле традиционной рисовой бумаги.
  - Сворачиваемые меню: сложные наборы кнопок спрятаны в компактные раскрывающиеся списки.

## Установка и запуск

```bash
# Клонировать репозиторий
git clone https://github.com/your-username/kanji-master.git

# Перейти в директорию проекта
cd kanji-master

# Установить зависимости
npm install

# Запустить в режиме разработки
npm run dev
```

После запуска приложение будет доступно по адресу `http://localhost:3000`.

### Сборка для публикации

```bash
npm run build
```

Собранные статические файлы будут находиться в папке `dist/` и могут быть размещены на любом статическом хостинге (GitHub Pages, Vercel, Netlify).
